# Nepal Disaster Update

Free, live information on disasters in Nepal: official figures, news, maps, road status, emergency numbers and the official relief fund, in English and Nepali.

**Live site:** https://nepaldisasterupdatelive.nxtimaginelabs.com

Built by Diamond Yogi, a Nepali student in New York, and running since 26 August 2026, the day of the Rasuwa flood.

## Why it exists

When a disaster hits, the numbers are scattered and they rarely match. This site puts them in one place and says where each one came from, so families in Nepal and abroad can stop guessing.

- Every figure names its source and the time it was published.
- Numbers come from official bulletins: Nepal Police, NDRRMA and the Office of the Prime Minister.
- Official sources are checked every few minutes, day and night, and readers' pages refresh on their own.
- No names of the dead or missing are published, and donation links go only to the government's own fund.

Listed as a source on ICIMOD's [Kyirong-Rasuwa Flood 2026](https://www.icimod.org/kyirong-rasuwa-flood-2026-nepal-china-border/) page.

## Use the live figures on your own site

Paste this into any page. The box updates itself and credits the source.

```html
<iframe src="https://nepaldisasterupdatelive.nxtimaginelabs.com/embed"
        title="Nepal disaster live figures" width="100%" height="150"
        style="border:0;max-width:520px" loading="lazy"></iframe>
```

## How it is built

A static site generated by plain Node scripts in `src/`, served from Cloudflare Pages, with small functions in `functions/` that read the sources. A scheduled GitHub Actions job reads official bulletins, checks each figure against strict rules, rebuilds the pages, audits them and publishes.

```bash
npm test
node src/build.mjs
node src/check.mjs
```

## Reuse it

The code is public so it can be reused for the next disaster, in Nepal or anywhere else. Corrections are welcome through the [contact page](https://nepaldisasterupdatelive.nxtimaginelabs.com/contact/).
